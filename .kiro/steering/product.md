# Product Overview

## What is this product?

A modern marketing and documentation website template built with Next.js 16 and HeroUI v3. The site showcases a SaaS product called "Exploratu Frontend" with multiple main sections: home, documentation, pricing, blog, and about pages.

## Target Use

This serves as a foundation for building beautiful, responsive web experiences quickly without requiring extensive design experience. It emphasizes a modern, professional aesthetic with dark/light mode support.

## Key Features

- Fast, optimized performance with Next.js 16
- Beautiful, accessible UI components via HeroUI v3
- Multiple content sections (home, docs, pricing, blog, about)
- Dark/light mode support with theme switching
- Responsive design working seamlessly across devices
- SEO-ready structure

## User Journey

1. Users land on the home page promoting the product
2. Navigate to docs, pricing, blog, or about sections via navbar
3. Switch between dark/light themes
4. Access links to GitHub, Twitter, and Discord communities

## Core Message

"Make beautiful websites regardless of your design experience" — emphasizing that HeroUI abstracts design complexity so developers can focus on functionality.
